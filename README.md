# AgentMart — AI Agent Store

A premium landing page for an AI agent marketplace: launch catalog, builder positioning, pricing, and call-to-action copy.

## Local preview

```bash
python3 -m http.server 4174
```

Then open `http://127.0.0.1:4174`.

## Deploy

This is a static site. Deploy the folder root to Cloudflare Pages, GitHub Pages, Netlify, or Vercel.
